Privacy Policy — Andropolis

Updated: 2026-02-11

Data Collection

Andropolis collects no user data. The application has no network access. No data is sent to any server, cloud service, or third party, under any circumstances.

Local Data

Game saves are plain text files stored on the device's external storage. They are owned by you and can be copied, moved, or deleted at any time. The application does not back them up, sync them, or read them for any purpose other than save/load.

Permissions

For optional background play, Andropolis requests the SCHEDULE_EXACT_ALARM permission, which controls the timing of local notifications only. This permission is not required. Without it, background notifications may be several minutes late.

Third-Party Components

Andropolis is built with AndroidX and Kotlin. These are part of the Android platform and do not collect data. The Micropolis simulation engine is open-source C++ code that runs entirely on the device.

Children's Privacy

Andropolis does not collect data and makes no claims about suitability for children. Parents should review the game content before allowing children to play.

Contact

For questions about this policy, open an issue at github.com/ds17f/andropolis.
